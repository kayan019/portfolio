# Njogu Wilson Kiiru — Software Engineering Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. It is designed for free deployment on GitHub Pages.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository named `your-username.github.io` (or any repository name).
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Your URL will be shown in the Pages settings.
